# Viva preparation

1. CNN: learns spatial filters for visual patterns.
2. Pooling: reduces feature-map size and compute.
3. Transfer learning: adapts pretrained features to a new task.
4. ResNet: skip connections improve optimization.
5. Overfitting: training improves while unseen-data performance degrades.
6. Validation: model selection without using final test data.
7. Precision: true positives / predicted positives.
8. Recall: true positives / actual positives.
9. Macro-F1: unweighted average per-class F1.
10. Backpropagation: chain-rule gradients for parameters.
11. SGD: stochastic sample-wise updates.
12. Momentum: exponentially accumulates gradient direction.
13. Nesterov: computes gradient at look-ahead position.
14. Grad-CAM: gradients weight convolutional activations for a class heatmap.
15. Grad-CAM is not pixel segmentation.
16. YOLO: one-stage object detector.
17. mAP: mean average precision under stated IoU protocol.
18. IoU: intersection over union.
19. Dice: twice intersection divided by total foreground sizes.
20. Why boxes cannot train U-Net: boxes do not identify exact defect pixels.
21. Parameters are learned weights; hyperparameters are configuration choices.
22. SVD factorizes a matrix into singular vectors/values.
23. Stratification preserves class proportions.
24. Data leakage contaminates evaluation with training/model-selection information.
25. Human review remains necessary under uncertainty and domain shift.
